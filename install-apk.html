📋 Mga Hakbang sa Pag-install

  1. I-scan ang QR code gamit ang camera ng iyong phone (o gamit ang Google Lens)
  2. I-tap ang Download button para i-download ang APK file
  3. Payagan ang download — may mag-pop-up na warning, i-tap lang ang "Download anyway" o "OK"
  4. Buksan ang APK file mula sa Downloads folder o notification bar
  5. I-enable ang "Install from unknown apps" kung hihingin ng phone
  6. I-tap ang "Install" at hintaying matapos
  7. Buksan ang app — payagan ang Camera permission para magamit
