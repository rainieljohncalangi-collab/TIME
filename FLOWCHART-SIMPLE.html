4. Simpleng Paliwanag

🚀 Paano gumagana:

  • Ang WEBSITE ay para sa teacher: gumawa ng quiz at tingnan ang resulta.
  • Ang DATABASE (MongoDB) ang nag-iimbak ng lahat ng quizzes at scores.
  • Ang ANDROID APP ang siyang nagsi-scan ng mga sagot ng estudyante gamit ang camera.
  • Kapag nag-sync ang phone, dumarating ang quiz mula sa website.
  • Kapag nag-scan ang phone, umuuwi ang score papunta sa website.
