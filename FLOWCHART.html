QR Code Data Format

Ang QR code sa OMR sheet ay naglalaman ng JSON na nire-render ng server:

{ "app": "TestSync", "name": "Student Name", "items": 50, "quizId": "6639f...", "pageStart": 1, "pageItems": 50, "paper": "long", "section": "Section A", "academicYear": "2025-2026", "recordFileId": "" }

Ginagamit ito ng parseSheetQr() sa Android para malaman ang student, quiz, page, at paper-type bago mag-scan.

6. Step-by-Step Build Guide (Paano Ito Ginawa)

Bahagi 1: Backend (server.js)

  1. Setup ng Express server — I-install ang express, cors, mongoose, bcryptjs, google-auth-library, qrcode. Gumawa ng server.js na nagsi-serve ng static HTML files at nagla-listen sa port 5000.
  2. Kumonekta sa MongoDB — Gamit ang mongoose.connect() sa MONGO_URI. May auto-retry kada 5 segundo kung hindi pa ready ang database.
  3. Gumawa ng Models — User, Quiz, Score, at RecordFile schemas. Ang answerKey ay ginagamit ng both web at Android (A=0, B=1, C=2, D=3, E=4).
  4. REST API Endpoints — /api/register, /api/login, /api/quizzes (CRUD), /api/scores, /api/record-files, /api/verify-account, /api/reset-password, /api/google-login.
  5. Google OAuth — OAuth2Client para sa /auth/google at /auth/google/callback. Nire-redirect sa google-callback.html na may user info sa URL params.
  6. Self-hosted QR — GET /api/qr?data=... gumagamit ng QRCode.toString() para mag-render ng SVG QR. Hindi na umaasa sa external API kaya gumagana kahit offline.
  7. APK download route — /install nag-serve ng page, /apk nag-download ng app-debug.apk.

Bahagi 2: Website Frontend

  1. Login & Register — log.html at register.html na may form na nag-call sa API gamit fetch(). May Google login button din.
  2. Dashboard — dashboard.html para sa teacher: gumawa ng quiz, mag-edit, mag-delete, at makita ang scores. May download APK button.
  3. OMR Sheet — testsync-omr-sheet.html na SVG-based. May 4 black anchor squares at bubbles na eksaktong tugma sa geometry ng OmrScanner.kt sa Android. Ang QR ay nasa tuktok.
  4. Install page — install-apk.html na may instructions at link sa /apk.

Bahagi 3: Android App

  1. Setup ng project — Gumawa ng android-scanner folder na may build.gradle.kts. Dependencies: CameraX (camera), ML Kit (QR detection), OpenCV (image processing), Retrofit (HTTP), Room (offline DB).
  2. MainActivity — Root activity. Nag-load ng OpenCV, nag-setup ng 4 tabs (Setup, Print, Scan, Results), nag-load ng saved IP, at nag-sync ng quizzes mula sa server.
  3. Camera + Flash — CameraX Preview + ImageCapture. May flash toggle at auto-focus na touch-to-focus.
  4. capturePaper() — Kumukuha ng high-quality photo, ini-save sa file, inaayos ang orientation base sa EXIF data.
  5. decodeQrThenScanAnswers() — ML Kit binabasa ang QR. Kung valid, kinukuha ang quiz, items, at paper type. Tapos ipapasa sa OmrScanner.
  6. OmrScanner.scanPaper() — OpenCV pipeline: gray → adaptive threshold → hanapin ang 4 na anchor squares → warpPerspective para i-align → readBubbles() para basahin ang mga sagot → compare vs answerKey.
  7. ResultActivity — Ipinapakita ang per-item results (Correct/Wrong/Blank) at ang total score. May save sa server at sa Room.
  8. RetrofitClient — Dynamic na base URL. Ang IP ay kino-configure sa Setup tab (default: 192.168.100.3:5000).

Bahagi 4: Pag-connect ng Lahat

  1. Same Wi-Fi — Dapat nasa parehong network ang computer (server) at ang phone para mag-communicate.
  2. Print ng OMR sheet — I-print ang testsync-omr-sheet.html sa 100% actual size.
  3. Build APK — Sa android-scanner folder, i-run ang ./gradlew assembleDebug para makagawa ng app-debug.apk.
  4. Install sa phone — I-upload ang APK sa /apk route, o i-install directly sa phone via USB/copy.
  5. Scan — Piliin ang quiz, ituro ang camera sa OMR sheet, at i-scan. May flash para sa low-light.
